## Usage

### 1. Quick Validation (Matplotlib)

Quickly checks trajectory quality and generates static images.

```bash
cd /mnt/local/Xiao_Yi/nuplan-devkit/GNN_Trans

# Evaluate 10 samples
python visualization/run_evaluation.py \
    --mode quick \
    --model_path diffusion_training_experiments/full_training/best_model.pt \
    --num_samples 10

# Show interactive plots
python visualization/run_evaluation.py --mode quick --show
```

**Output**:
- `sample_*.png` - Per-sample trajectory comparison plot
- `summary.png` - Aggregate statistics plot
- `evaluation_report.json` - Detailed data

### 2. Bokeh Visualization

Interactive HTML visualisation with timeline playback.

```bash
# Generate Bokeh visualisation
python visualization/run_evaluation.py \
    --mode bokeh \
    --model_path diffusion_training_experiments/full_training/best_model.pt \
    --num_samples 5
```

**Output**:
- `diffusion_visualization.html` - Can be opened in a browser
- `scenario_*.pkl` - Scenario data files
- `summary.json` - Statistics summary

### 3. Full Evaluation

Runs both visualisations together.

```bash
python visualization/run_evaluation.py \
    --mode full \
    --model_path diffusion_training_experiments/full_training/best_model.pt \
    --num_samples 10
```

### 4. Statistics Analysis

Large-scale statistical analysis.

```bash
python visualization/run_evaluation.py \
    --mode stats \
    --model_path diffusion_training_experiments/full_training/best_model.pt \
    --num_samples 100
```

## Visualisation Content

### Matplotlib Quick Validation

Each sample produces 4 subplots:

1. **Trajectory comparison** - GT vs Generated trajectory positions
2. **Speed curve** - Speed over time
3. **Danger score** - GT vs Generated danger comparison
4. **Sample information** - SVO angle, validity checks, metrics

Aggregate statistics plot:
- Danger score scatter plot
- Danger improvement distribution histogram
- Speed distribution box plot
- Summary statistics

### Bokeh Visualization

- **Scenario Tabs** - One tab per scenario
- **Timeline Hover** - Hovering the mouse shows the time point
- **Danger comparison bar chart** - Summary chart at the bottom

## Core Metrics

### Main Metrics (Project-Specific)

| Metric | Description | Computation |
|------|------|----------|
| Margin Met Rate | Proportion with Gen > GT + 0.5 | Successes / total |
| Mean Gen Danger | Mean absolute danger of generated trajectories | Mean of danger_score |
| Valid Rate | Proportion with speed ≤ 80 m/s and no NaN | `check_kinematic_validity()` |
| Danger Improvement | Mean of Gen - GT | Difference of means |

### Literature-Aligned Standard Metrics (`standard_metrics.py`, computed automatically)

| Metric | Description | Reference |
|------|------|---------|
| **Collision Rate** | Proportion of ego-agent collisions (centre distance < 2.0m) | AdvDiffuser, SafeBench |
| **Mean Min Distance** | Mean ego-agent minimum distance (m) | KING, SaFeR |
| **Mean TTC** | Mean time to collision (s); inf when there is no collision | SaFeR, AdvSim |
| **Near Miss Rate** | Proportion with close-range contact (TTC < inf) | - |
| **Kinematic Feasibility** | Proportion satisfying accel ≤ 8 m/s² and jerk ≤ 15 m/s³ | KING |
| **Jerk JSD** | Jensen-Shannon divergence between generated vs GT jerk distributions | AdvDiffuser |

Standard metric results are automatically written to the `standard_metrics` field of `evaluation_report.json`.

## Physical Constraint Thresholds

| Parameter | Value | Description |
|------|-----|------|
| Valid Speed | ≤ 80 m/s | Covers motorway scenarios (~288 km/h) |
| Max Accel (feasibility) | 8 m/s² | KING / AdvDiffuser convention |
| Max Jerk (feasibility) | 15 m/s³ | KING / AdvDiffuser convention |
| Collision threshold | 2.0 m | Half the sum of vehicle widths |

## Caveats

1. **GPU memory**: watch the GPU memory limit during batch evaluation
2. **Bokeh dependency**: Bokeh mode requires the `bokeh` package (`pip install bokeh`)
3. **Model path**: make sure `model_path` points correctly to the checkpoint
4. **Data path**: `data_dir` should contain `danger_pair_features_*.pkl` files

## Extended Usage

### Python API

```python
from visualization import MatplotlibVisualizer

viz = MatplotlibVisualizer(
    model_path="best_model.pt",
    data_dir="diffusion_danger_model/danger_pair_scenarios"
)

results = viz.evaluate_samples(num_samples=20)
```

### Custom Analysis

```python
from visualization import recover_trajectory_from_increment, check_trajectory_validity

# Recover the trajectory from increments
traj = recover_trajectory_from_increment(increments, start_pos, start_heading, vx, vy)

# Check validity
validity = check_trajectory_validity(traj)
print(validity['metrics'])
```

## Integration with nuBoard

Full NuBoard integration requires:
1. NuPlan scenario data format
2. Map database connection
3. Simulation result path

The current Bokeh mode provides a lightweight alternative that does not need the full NuPlan dependencies.
