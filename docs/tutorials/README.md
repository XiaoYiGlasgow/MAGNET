# GNN_Trans Tutorial Overview

> Documentation conventions:
> - `Project A`: trajectory prediction / baseline / planning
> - `Project B`: danger scenario generation / diffusion / danger visualisation

This tutorial series is intended for researchers using this project for the first time, and introduces from scratch how to run the two complete pipelines: trajectory prediction and danger scenario generation.

---

## What the project is

GNN_Trans is an autonomous driving research framework based on the NuPlan dataset, containing two independent research lines:

| Research line | Goal | Core method |
|--------|------|----------|
| **Trajectory prediction** | Predict the future trajectories of surrounding vehicles and the ego vehicle | GNN + Transformer encoder |
| **Danger scenario generation** | Generate adversarial scenarios that are more dangerous than real data | Diffusion model + kinematic parameterisation |

The two lines can be run independently or combined (danger trajectories generated by Diffusion can serve as challenge inputs to NuPlan simulation).

## 5-minute quick check (change nothing, just run)

If you only want to confirm first that the environment and code work, run the following commands:

```bash
# Activate the environment
conda activate nuplan

# 1. Trajectory prediction: NuPlan planning simulation (about 10 seconds)
cd /mnt/local/Xiao_Yi/nuplan-devkit
python GNN_Trans/run_nuboard_simulation.py --no-nuboard
# Expected output: Number of successful simulations: 2, failed: 0

# 2. Danger scenario generation: statistical evaluation of the current best model (about 2 minutes)
cd /mnt/local/Xiao_Yi/nuplan-devkit/GNN_Trans
python visualization/run_evaluation.py \
    --mode stats \
    --model_path experiments/danger_generation/training_runs/full_training_v3_10/best_model.pt \
    --data_dir diffusion_danger_model/danger_pair_scenarios \
    --processed_data_dir diffusion_danger_model/processed_data \
    --num_samples 40 --min_gt_danger 2.0 --device cuda
# Expected output: Valid Rate 100%, Margin Met 87.5%, Danger Improvement +369.62
```

Both commands run successfully → the environment is fully working, and you can continue with the detailed tutorials.

## If you run into problems, check these points first

1. **ModuleNotFoundError** → confirm you are running in the `conda activate nuplan` environment
2. **Path does not exist** → confirm the working directory is correct (see the beginning of each tutorial)
3. **CUDA out of memory** → reduce `batch_size` (change to 4 or 2)
4. **NuPlan database not found** → check whether `/mnt/local/Xiao_Yi/nuplan-devkit/nuplan/dataset/` is mounted
